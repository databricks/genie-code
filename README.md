# Genie Code

This repository hosts released builds and the public issue tracker for Genie Code.

## Releases

Download the latest builds from the [Releases](https://github.com/databricks/genie-code/releases) page.

## Reporting issues

Found a bug or have a feature request? [Open an issue](https://github.com/databricks/genie-code/issues). Please do not include credentials, tokens, or confidential information in issue reports.

For security vulnerabilities, follow the [security policy](SECURITY.md) instead of opening a public issue.
